# astrbot_plugin_course

AstrBot 课表插件：绑定个人课表后，可输出**今日课表 / 明日课表 / 本周课表 / 下周课表**，并可配置**每日自动推送**和**开课前提醒**（提前时间可自定义）。

## 环境要求

- AstrBot：建议 **>= 4.19.4**
- 插件依赖：见 `requirements.txt`
- 安装了 playwright 环境，用于渲染课表。

## 安装

1. 在Astrbot控制台中选择Astrbot插件→右下角加号→从文件安装，选择本插件进行安装，依赖会自动安装;或下载源代码zip，手动将本插件目录放到 AstrBot 的插件目录，在插件目录执行 `pip install -r requirements.txt`安装依赖。
2. 在 AstrBot WebUI 中启用/重载插件。

## 指令

### 课表管理

- `/绑定课表`：进入绑定流程（120秒内发送 Excel、Word、文本型 PDF、JSON、HTML、ICS 或 PNG/JPG/WEBP；发送"退出"可取消）。非 ICS 文字内容由课表解析模型处理，图片按模型配置路由识别。
- `/删除课表`：删除已绑定的个人课表
- `/课表时间`：设置非 ICS 课表使用的个人节次作息
- `/开启群提醒`、`/关闭群提醒`：只切换当前群的课前提醒。绑定所在群默认开启，其他群默认关闭，需由课表所有者在目标群手动开启。

### 课表查询

- `/今日课表`：输出今日课表图片
- `/明日课表`：输出明日课表图片
- `/本周课表`：输出本周课表图片
- `/下周课表`：输出下周课表图片

### 配置管理

- 在 AstrBot WebUI 插件管理页打开本插件的配置（齿轮），可分别选择“课表解析模型”和“视觉识别模型”。视觉识别模型仅用于课表附件图片解析及 `/课表时间` 图片识别，适用于课表解析模型不支持视觉输入或希望分模型运行的情况；留空时沿用课表解析模型，若两项都留空则跟随当前会话模型。显式选择的模型不可用时会提示检查对应配置，不会静默切换。该设置不影响普通对话或全局模型配置。

- `/设置每日推送`：配置每日课表自动推送（回复"开启 HH:MM"如"开启 07:00"，或回复"关闭"禁用）
- `/设置提醒时间`：配置开课前提醒的提前时间（回复分钟数，范围 1-120）
- `/查看设置`：查看当前配置

## 导入课表

1. 在想默认接收课前提醒的群发送 `/绑定课表`，然后在同一会话内发送一份附件。
2. 支持 `.ics`、`.xls`、`.xlsx`、`.docx`、文字型 `.pdf`、UTF-8 `.json` / `.html` / `.htm` 和 PNG/JPG/WEBP 图片，单个附件上限 12 MiB。旧版 Word `.doc` 请先另存为 `.docx`；扫描版 PDF 请发课表截图。
3. 若课表只有星期和周次，先发送 `课表补充 第一周周一 2026-09-07`（换成你的实际日期，必须是星期一），再发附件。模型按星期与周次提取精简记录，由插件展开为实际日期；周次范围最多 60 周。若只有节次，建议先用 `/课表时间` 保存作息，或在同一条补充消息中写出节次对应的起止时间。补充信息也可随附件发送。绑定处理阶段有独立超时；超时后原课表保留，可重新发送附件。
4. ICS 直接导入，不调用模型。其他附件的文字由“课表解析模型”处理；图片由“视觉识别模型”处理，留空时沿用课表解析模型（两项都留空则使用当前会话模型）。`/课表时间` 图片识别同样使用视觉识别模型；直接发送作息文本或 JSON 文件不调用模型。附件内容会发送给所选模型服务处理，请按服务的数据处理政策选择模型。导入失败会保留原课表；导入后建议用 `/本周课表` 核对结果。

## 设置课表作息

1. 发送 `/课表时间`，在同一会话发送作息时间表。可以在绑定前设置，也可以绑定后更新。
2. 支持粘贴 JSON，例如 `{"1":["08:25","09:10"],"2":["09:15","10:00"]}`；纯文本每行一节，例如 `第1节 08:25-09:10`；也可发送 UTF-8 `.json` / `.txt` 文件或一张作息表截图。图片会交给配置的“视觉识别模型”识别；该项留空时按上述模型选择规则处理。
3. 新表会替换原设置。对记录了节次、且新表覆盖其完整节次范围的非 ICS 课程，从第一节开始时间算到最后一节结束时间。查询、每日推送、课前提醒均使用调整后的时间，各群共享这份设置。
4. 原生 ICS、没有节次的记录，以及新表未覆盖完整节次范围的课程，均保持导入时的时间。旧版已导入但未记录节次的课表，可重新发送带节次的原始文件或图片。日期与星期仍以课表为准；只有周次时仍需补充第一周周一日期。

## 跨群使用

- 同一机器人下，同一账号在不同群查询的是同一份个人课表，无需重复绑定；其他群成员只能查询自己的课表。
- 初次绑定所在群默认开启课前提醒；其他群请本人在目标群发送 `/开启群提醒`。发送 `/关闭群提醒` 只关闭当前群。群提醒会向群内公开课程名和地点。
- 重新导入会更新各群查询到的课表，保留首次绑定会话和各群的提醒设置。私聊绑定保留原有私聊课前提醒，不会自动开启任何群。
- 每日课表推送是独立设置，仍只发往首次绑定的会话，不跟随群提醒开关。

## 每日推送

- 使用 `/设置每日推送` 开启后，插件会在每天指定时间自动推送当日课表图片。
- 推送时间格式：HH:MM（24小时制，例如：07:00、18:30）
- 每天只推送一次。

## 开课提醒

- 插件会每 60 秒检查一次即将开始的课程。
- 默认提前 15 分钟提醒，可通过 `/设置提醒时间` 自定义（1-120 分钟）。
- 命中后会主动发送提醒消息，内容包含课程名与地点（若地点为空则仅发送课程名）。
- 提醒独立投递到已启用的群聊；发送失败的目标会在后续检查中重试。

## 数据存储

为避免插件更新/重装覆盖数据，课表与绑定信息会存储在 AstrBot 数据目录下：

- `data/plugin_data/astrbot_plugin_course/bindings.json`
- `data/plugin_data/astrbot_plugin_course/ics/*.ics`

## 常见问题

- 渲染图片失败：确认 AstrBot 安装了 Playwright 环境，必要时查看 AstrBot 日志中的报错信息。
